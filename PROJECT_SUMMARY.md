## 🚀 **Quick Setup for Demo**

### **Start System**
```bash
docker-compose up -d
# Frontend: http://localhost:3000
# Backend: http://localhost:5000
```

### **Run Tests**
```bash
# Backend tests
cd server && npm test

# Frontend tests
cd client && npm test

# E2E tests
cd e2e && npm run cypress:run
```
