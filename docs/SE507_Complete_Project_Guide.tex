\section{Project Overview}

\subsection{System Architecture}

The Library Management System is built using modern web technologies:

\begin{itemize}[leftmargin=*]
    \item \textbf{Frontend:} React.js with Material-UI for responsive design
    \item \textbf{Backend:} Node.js with Express.js for API services
    \item \textbf{Database:} MongoDB for data persistence
    \item \textbf{Authentication:} JWT-based secure authentication
    \item \textbf{Deployment:} Docker containerization for easy setup
\end{itemize}

\subsection{Key Features}

\begin{enumerate}[leftmargin=*]
    \item \textbf{User Management:} Role-based access control (Librarians \& Members)
    \item \textbf{Book Management:} Complete CRUD operations for library inventory
    \item \textbf{Search \& Filter:} Advanced search capabilities with multiple filters
    \item \textbf{Authentication:} Secure login/logout with session management
    \item \textbf{Responsive Design:} Mobile and desktop compatibility
    \item \textbf{Data Validation:} Comprehensive input validation and error handling
\end{enumerate}

\section{Technical Setup}

\subsection{Quick Environment Setup}

\subsubsection{Prerequisites}
\begin{itemize}[leftmargin=*]
    \item Node.js (v16 or higher)
    \item Docker Desktop
    \item Git
    \item Code editor (VS Code recommended)
\end{itemize}

\subsubsection{Setup Steps}
\begin{lstlisting}[language=bash]
# 1. Clone repository
git clone <repository-url>
cd LibraryManagement

# 2. Install dependencies
cd server && npm install
cd ../client && npm install
cd ../e2e && npm install

# 3. Setup environment
cp server/.env.example server/.env
cp client/.env.example client/.env

# 4. Start with Docker
docker-compose up -d

# 5. Verify setup
# Frontend: http://localhost:3000
# Backend: http://localhost:5000
\end{lstlisting}

\subsection{Running Tests}

\subsubsection{All Tests}
\begin{lstlisting}[language=bash]

# Frontend tests

# E2E tests
