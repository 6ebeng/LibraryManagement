\section{Purpose}
\label{sec:Purpose}
This Software Requirements Specification (SRS) document describes the functional and non-functional requirements for the Quiz Web App. This web application allows users to create, take, and manage quizzes across various categories. It also features an administrative section for managing users, quizzes, categories, and questions, and integrates with an external AI API for assistance.

\section{Document Conventions}
\label{sec:DocumentConventions}
This document uses standard conventions for SRS documents. Requirements are stated in a clear and concise manner. ``Shall'' is used to denote mandatory requirements. ``Should'' is used to denote desirable but not mandatory requirements. ``May'' is used to denote optional requirements.

\section{Product Scope}
\label{sec:ProductScope}
The Quiz Web App is designed to be a comprehensive platform for creating, delivering, and managing quizzes. Key features include:
\begin{itemize}
    \item User registration and authentication.
    \item Role-based access control (User, Administrator).
    \item Quiz creation with various question types (e.g., multiple-choice, true/false).
    \item Categorization of quizzes.
    \item Quiz taking functionality with immediate feedback and scoring.
    \item Leaderboards to display top scores.
    \item Administrative interface for managing users, quizzes, categories, and questions.
    \item Integration with an external AI API (e.g., OpenAI) for features like question generation assistance or automated feedback (details to be specified).
\end{itemize}
The system aims to provide an engaging and interactive learning and assessment experience for users, while offering robust management capabilities for administrators.
